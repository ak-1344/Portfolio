# Portfolio v2.0.0 - Release Notes

**Release Date:** November 17, 2025  
**Status:** ✅ Production Ready

---

## 🎯 Overview

Portfolio v2.0.0 is a complete overhaul of the frontend with full Supabase backend integration, featuring dynamic content management, project pinning, certifications showcase, and mobile-first responsive design.

---

## ✨ New Features

### 1. Project Management
- **Project Pinning System**
  - Pin up to 3 featured projects with custom order
  - Visual pin badges with order numbers
  - Separate sections for pinned and recent projects
  - Horizontal scrollable cards on mobile (280px width)

### 2. Certifications Showcase
- Dedicated certifications page and homepage section
- Certification cards with status badges (Active/Expired)
- Filterable by status (All, Active, Expired)
- Display credential IDs and verification links
- Skills tags and issue/expiry dates
- Horizontal scrollable on mobile

### 3. Enhanced Blog System
- Dynamic excerpt generation
- Auto-calculated read time
- Improved blog detail pages with proper formatting
- Display order support
- Preserve whitespace for multi-line content

### 4. Contact Form Integration
- Working contact forms on homepage and /contact page
- Form validation (name, email, message length)
- Success/error feedback with icons
- Supabase integration with contact_messages table
- Status tracking (unread, read, replied, archived)

### 5. Display Order System
- All content types support custom display ordering
- Admin-controlled content prioritization
- Fallback to created_at for items without display_order

### 6. Dynamic About Page
- Fetches current NOW projects dynamically
- Skills showcase with badges
- Timeline section ready for expansion

## 🚀 Setup & Deployment

### Environment Variables Required
```env
NEXT_PUBLIC_SUPABASE_URL=your-project-url.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

### First-Time Setup
1. Copy `.env.example` to `.env.local`
2. Add Supabase credentials
3. Run RLS setup script in Supabase SQL Editor
4. Install dependencies: `pnpm install`
5. Run dev server: `pnpm dev`

### Build & Deploy
```bash
pnpm build    # Production build
pnpm start    # Start production server
```

## 📝 Migration Notes

### From v1.0 to v2.0
- Database schema changed significantly
- All content needs re-entry via admin portal
- New type definitions require code updates
- Contact form now uses Supabase instead of API routes

### Breaking Changes
- `Blog.summary` → `Blog.excerpt`
- Contact form status: "new" → "unread"
- Projects require display_order field
- Certifications table is entirely new
